## 数据流

1. **数据**：`data/synth.py` 生成确定性合成语料 → `DeepSelect` 去重/评分/课程排序 → `BatchLoader` 编码。
2. **模型**：`AscendTransformer` = 嵌入 + N×(`MoEDecoderBlock`) + LM head；每个块 = MLA 注意力 + MoE FFN + 残差 + RMSNorm。
3. **训练**：`Trainer` 驱动后端 `train_step`，mock 后端 skill 单调上升、loss 下降。
4. **服务**：`serving/http_server.py` 暴露 OpenAI 兼容 `/v1/completions`。
5. **通信**：`comm/deepep.py` 模拟 MoE 专家并行的 dispatch/combine。

## 设计取舍

- **零依赖**：张量、YAML、HTTP、MCP 全部用标准库/纯 Python，保证托管环境可跑。
- **确定性**：所有随机性来自 `md5(key)` 播种的 `random.Random`，同一 key 恒同值，基准可复现。
- **可训练**：mock 后端把「能力」建模为 skill 标量，训练动作真实改变预测正确性。
